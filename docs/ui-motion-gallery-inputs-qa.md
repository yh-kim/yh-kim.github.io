# UI·모션 갤러리 입력 컴포넌트 QA


화면 캡처는 개인 로컬 보관소에 저장하며 저장소에는 포함하지 않는다.
2026-10-19, `/p/ui-motion/components/`의 목록 카드에서 확인했다. 브라우저 폭은 1440 × 900px과 390 × 844px이었다. 데스크톱 카드 폭은 559px, 모바일 카드 폭은 349px(데모 영역 347px)이었고, 여섯 카드 모두 데모 내부와 카드 바깥의 가로 넘침이 없었다. 조작 중 URL 해시는 빈 값으로 유지됐다. 갤러리 상세는 `자세히 보기` 버튼을 눌렀을 때만 열리는 구조다.

| 컴포넌트 | 목록에서 확인한 동작 |
| --- | --- |
| 파일 업로더 | 샘플 PDF 선택 → 진행률 표시 → 취소 → 다시 시도. 390px에서도 샘플 업로드가 시작됐다. |
| 드롭다운 액션 메뉴 | 복제로 목록 1개→2개, 이름 변경과 보관 상태 반영. 390px에서 아래 화살표와 Escape로 메뉴 탐색·닫기. |
| 계정 설정 탭 | 알림·보안 탭 변경, 설정 토글, 저장 결과 확인. 저장 버튼은 저장 후에도 초점 가능한 상태를 유지한다. |
| 버튼과 저장 상태 | 오류 상태 → 다시 시도, 북마크·팔로우 선택 상태, 비활성 버튼 확인. 390px에서도 저장 동작을 시작했다. |
| 뉴스레터 구독 폼 | 빈 폼의 항목별 오류, 유효한 입력의 처리 중·완료 상태. 390px에서도 완료를 확인했다. 실제 이메일은 발송되지 않는다. |
| 태그 입력 | Enter 추가, 중복 오류, 추천 태그 추가, 태그 삭제와 미리보기 갱신. 390px에서도 추천·삭제를 확인했다. |

실제 파일 선택기의 OS 대화상자와 실제 파일 업로드는 실행하지 않았다. 파일 형식·5MB 크기 검증은 코드 경로를 확인했으며, 브라우저에서는 제공된 샘플 PDF로 진행·취소·재시도를 검증했다. 서버 전송은 없다.

독립 실행 HTML 6개도 `node scripts/test-ui-motion-showcase.mjs --export-previews`로 다시 생성해 로컬 서버에서 각각 열었다. 업로더의 취소·재시도, 메뉴 복제, 설정 저장과 초점 유지, 저장 오류와 북마크, 뉴스레터 오류·완료, 태그 추가·중복 오류가 동작했다. 갤러리 업로더에서는 취소→재시도→완료→지우기 동안 초점이 다음 제어로 유지되는 것도 확인했다. 브라우저 콘솔 오류는 없었다.

캡처: 1440px 데스크톱 목록 QA (개인 로컬 보관).

캡처: 390px 모바일 목록 QA (개인 로컬 보관).

처리 중 목록→상세 이동도 별도로 확인했다. 업로드20% 상태를 이어받아100%까지 완료했고, 저장 중 오류 결과와 구독 폼의 입력·진행·완료 메시지도 유지됐다. 진행 막대는 scaleX를 사용하며, SVG 아이콘의 선 굵기는1.7px로 맞췄다. 구독 필드는 고정 접근성 이름과 오류 설명 연결을 제공한다.
