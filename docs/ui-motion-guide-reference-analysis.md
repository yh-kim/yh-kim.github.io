2026-10-16 기준. A·B는 공개 포트폴리오의 **정지 이미지**를 실제 브라우저에서 열고 확대했으며, 원본 파일을 임시 폴더에 받아 픽셀 크기를 확인했다. C는 실제 브라우저에서 조작한 결과와 [기존 검증 기록](ui-motion-guide-verification.md)을 사용했다. 아래의 비율·배치 설명은 이미지에서 관찰한 결과이고, 별도 표기가 없는 CSS 수치는 새 데모를 위해 **의도적으로 재설계**할 값이다. 포트폴리오의 축소 목업은 실제 브라우저 viewport나 컴포넌트 CSS를 실측할 근거가 아니다.

## 원본에서 확인된 값과 재설계 범위

- A 페이지가 표시한 팔레트는 `#010308`, `#E4F1FF`, `#1B2E64`, `#A9CEFE`, `#1D48C4`, `#629FFD`, `#A37306`이다. 이는 **원본 페이지에 표시된 값**이며 데모 토큰을 동일하게 복제한다는 뜻이 아니다. 출처: [Conceptzilla / Dribbble](https://dribbble.com/shots/27748221-AI-Agent-Website-Design).
- B 포트폴리오의 Typography and colors 이미지에 **Manrope**와 `#75FC96`, `#D13817`, `#000000`, `#ADADAD`, `#FFFFFF`가 직접 인쇄되어 있다. 출처: [PlanIQ / Behance](https://www.behance.net/gallery/251693759/PlanIQ-SaaS-Project-Management-Dashboard-UIUX). 데모는 접근성·블로그 폭을 고려해 별도 값으로 조정할 수 있다.
- A·B 이미지로 원본의 motion duration, easing, trigger, 반복, 중단 조건은 알 수 없다. 가이드의 애니메이션은 **이 디자인에 맞춰 새로 설계한 모션**으로 표시한다. 정지 이미지의 상태 표시는 실제 클릭 동작 확인과 다르다.
- A·B의 로고, 브랜드 이름, 문구, 사진, 캡처 이미지는 데모 자산으로 배포하지 않는다. 이 기록의 이미지 링크는 관찰 출처이며, `/tmp/ui-guide-reference/`의 파일은 비교 작업용이다.

## 현재 글과 비교 기준

수정 전 [히든메모 글](/p/hidden-memo/ui-motion-guide/)의 본문은 MORI 공간 예약을 Warm Minimal·Editorial·Technical·Bold Graphic의 네 변주로 보여 줬다. 새 결과는 같은 URL과 글 메타데이터를 유지하면서 A와 B의 서로 다른 **화면 유형과 정보 구조**를 큰 대표 화면으로 보여 준다. 최종 캡처는 1440px에서 원본의 주요 화면과 결과를 비슷한 표시 폭으로 놓고 전체 구도, 핵심 영역 비율, 타이포 위계, 정보 밀도, 표면·레이어를 비교했다. 이 비교는 **시각적 판단**이며 픽셀 복제를 목표로 하지 않는다.
