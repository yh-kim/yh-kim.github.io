# UI·모션 갤러리 참고 자료 확인

2026-10-19에 제공된 각 사이트의 공개 기본 페이지를 확인했다. 웹 텍스트 추출로 라이선스 문구와 소개를 조사하고, 별도 Chrome 탭에서 17개 URL을 순서대로 실제 렌더링해 접근성 트리와 화면을 확인했다. 화면 크기는 바꾸지 않았고, 로그인·가입·유료 동작은 누르지 않았다. 이전 [제3자 라이선스 메모](ui-motion-third-party-license.txt)와 [가이드 참고 화면 기록](ui-motion-guide-reference-analysis.md)은 읽었지만 현재 자료 확인의 증거로 사용하지 않았다. 이번 작업은 참고 자료 조사이며 외부 코드, 이미지, 폰트 파일을 가져오거나 재배포하지 않는다.

## 이 정적 갤러리에 적용할 관찰

- 기존 갤러리의 컴포넌트와 카테고리 탐색을 중심에 두고, 데모 하나마다 **이름, 실제 화면, 사용자의 입력, 바뀐 상태, 다시 시작하는 방법**을 짧게 연결한다. 사용자는 효과를 보는 데서 끝나지 않고 동작을 이해할 수 있다.
- 마우스 hover만으로 끝내지 말고 클릭·키보드 조작을 제공한다. 자동 재생은 짧고 사용자가 반복을 멈출 수 있게 하며, `prefers-reduced-motion`에서는 움직임을 줄인다. Animata가 명시적으로 알리는 focus·screen-reader·reduced-motion 지원도 확인 기준으로 삼는다.
- 긴 장식 애니메이션보다 클릭/스크롤/키보드 같은 직접 입력에 반응하는 짧은 피드백을 먼저 다룬다. React 전용 컴포넌트를 그대로 가져오지 않고, 원리만 보고 기존 정적 HTML/CSS/JS 구조 안에서 새로 작성한다.
- 이미지나 글꼴을 실제로 추가할 때는 자산별 페이지, 기여자, 라이선스 파일을 기록한다. Unsplash 무료 이미지와 Unsplash+ 이미지를 혼동하지 않는다. 이번 조사에는 유료 자료, 로그인·구독, API 키를 요구하는 사용 흐름을 수행하지 않았다.

## 확인 한계

이번 확인은 제공된 각 기본 URL의 공개 페이지를 여는 데 한정했다. 웹 텍스트 추출과 브라우저 화면의 결과가 달랐던 페이지는 표에 각각 기록했다. Chrome 탭에서 React Bits는 본문 접근성 트리가 비어 있었고, Noto Sans KR specimen은 Google Fonts 일반 탐색/정보 화면만 보이며 specimen 내용은 나타나지 않았다. OriginKit, Motion Primitives, Unicorn Studio는 화면 캡처와 접근성 정보로 첫 화면을 확인했다. 다른 사이트도 전체 자료를 전수 조사하거나 모든 데모를 직접 실행한 것은 아니다. UI 라이브러리마다 개별 구성요소의 파일 라이선스·저자·포함된 이미지/폰트가 다를 수 있다. 표에 명시한 일부 오픈소스 소개 문구만으로 모든 하위 항목의 재사용 권리가 확인된 것은 아니다. 이 조사 결과는 동작과 설명 패턴을 참고하기 위한 것이고, 외부 코드를 복사하거나 외부 자산을 사이트에 넣을 근거로 삼지 않는다.
