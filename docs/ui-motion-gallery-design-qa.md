# UI·모션 갤러리 디자인 확인

2026-10-19. 로컬 `/p/ui-motion/`를 브라우저에서 확인했다. 스크린샷은 미리보기 컴포넌트가 마운트된 뒤 촬영했다.

| 1440 × 900 | [목록 화면](assets/ui-motion-gallery/site-after-main-1440.jpg) | [디자인 기준](assets/ui-motion-gallery/site-after-design-1440.jpg) | 사이드바 208px, 카드 559px·미리보기 557px. 두 열을 유지하고 첫 카드가 y=262px에서 시작한다. 가로 넘침 없음. |
| 390 × 844 | [목록 화면](assets/ui-motion-gallery/site-after-main-390.jpg) | [디자인 기준](assets/ui-motion-gallery/site-after-design-390.jpg) | 브라우저 콘텐츠 폭 375px, 카드 349px·미리보기 347px. 한 열이며 첫 카드가 y=281px에서 시작한다. 가로 넘침 없음. |

목록의 첫 두 미리보기에서 입력과 버튼이 실제 폭을 사용하고, 모바일에서는 제어가 세로로 재배치되는 것을 확인했다. 상세 보기의 데모와 가이드를 1440px·390px에서 열어 읽기 및 스크롤 상태도 확인했다. 모바일 디자인 기준 화면에서는 현재 위치와 본문이 정상 표시된다.

작은 보조 글자에 쓰는 `#696e79`는 가장 어두운 갤러리 종이색 `#f7f6f3`에서도 대비 약 4.73:1이다. 탐색·분류·상세 보기의 주요 제어는 최소 높이 44px로 맞췄다.

스크린샷은 각 화면의 첫 뷰포트다. 목록 아래쪽의 모든 컴포넌트 상태와 1180px 중간 폭의 기능 검증은 별도 통합 확인 범위다.
