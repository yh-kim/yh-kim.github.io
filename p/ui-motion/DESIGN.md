# UI·모션 컴포넌트 갤러리

2026-10-19. 적용 범위는 `/p/ui-motion/components/`와 `engine.js`의 비대표 요소 12개다. 기존 AI Workspace·Project Dashboard의 완성 화면은 각자의 장면 토큰을 유지한다. 갤러리는 탐색의 일관성을 담당하고, 데모의 표면·밀도·전환은 용도에 맞게 달라진다.

## 탐색 화면

실제 원본: `js/ui-motion-showcase/gallery.css`. Shadow DOM으로 블로그와 격리한다.

| 역할 | 값 | 사용 이유 |
| --- | --- | --- |
| 바탕 | `#f7f5f0` | 밝은 종이 표면. 데모보다 배경이 먼저 보이지 않게 한다. |
| 표면 | `#fffefa` | 입력·검사 패널의 구획을 색 차이와 얇은 선으로 구분한다. |
| 본문 | `#242724` | 작은 한국어와 숫자의 대비를 확보한다. |
| 보조 텍스트 | `#62645e` | 배경 대비 약 5.5:1. 설명도 본문처럼 읽을 수 있게 한다. |
| 구분선 | `#d8d8cf` | 구획을 나누되 모든 카드를 굵게 감싸지 않는다. |
| 강조 | `#a43d29` | 링크·중요 피드백의 제한된 사용. 파란 광원·그라데이션과 분리한다. |
| 키보드 초점 | `#265ec8`, 3px, offset 3px | 선택 색과 초점 색을 구분하고 흰색/종이 위에서 보이게 한다. |

글꼴은 시스템 `-apple-system`, `BlinkMacSystemFont`, `Apple SD Gothic Neo`, `sans-serif`. 웹폰트 요청은 없다. 제목 29–44px/1.18/720, 카드 제목 19px/1.35/680(모바일 20px), 본문 14px/1.6, 설명 12px/1.7(모바일 13px), 보조 라벨 11px. 제목 자간 -0.04~-0.055em, 본문 기본 자간. 한국어 `word-break:keep-all`과 `overflow-wrap:anywhere`를 함께 쓴다.

최대 폭 1536px, 좌우 여백 40px → 1180px에서 28px → 390px에서 18px. 데모 목록은 1200px 이상 3열, 600–1199px 2열, 599px 이하 1열이다. 열 간격 22px, 행 간격 30px. 제목과 검색 영역은 단단한 상하 경계로 나누고 목록 앞 큰 히어로를 두지 않는다. 일반 공간은 4/8/12/16/20/24/28/32px. 조작부 최소 높이 44px, 검색·분류는 46px.

탐색 프레임 반경 4–5px, 검사창 6px. 목록에는 그림자가 없다. 상세창만 `0 24px 80px #1c25192b`를 쓰고 오버레이는 `#1d251e91`. 아이콘은 직접 그린 SVG, 24 뷰박스, 18px(보조 링크 16px), 선 굵기 1.7, 둥근 끝/연결로 통일한다.

## 데모의 서로 다른 맥락

실제 원본: `js/ui-motion-showcase/component-design.js`. HTML은 `componentMarkup`, CSS는 `componentCSS`, 동작은 `engine.js`의 `wire`. 미리보기/상세/내보내기는 이 세 원본을 함께 사용한다.

전체 보기의 최소 높이는 레이어 540px, 프리셋 520px, 처리/차트/필터 480px, 입력/일정 440px, 선택/검토창 400px, 작업 상세 560px이며 작업 추가는 내용 높이를 사용한다. 큰 장면의 높이를 폼에 적용하지 않는다. 모바일 전체 보기는 상하22px·좌우18px 여백이다.

공통 읽기 색은 본문 `#242724`, 표면 `#fffdfa`, 경계 `#d7d5ce`, 보조 `#696d68`, 동작 강조 `#b0472f`, 오류 `#a13232`, 성공 `#426b55`. 어두운 영역은 `#29312f` 바탕에 `#f1f0e9` 글자. 제어부는 최소 44px, 원형 필터/탭은 선택 기능에만 쓴다. 큰 숫자는 tabular 표기와 충분한 폭을 둔다.

- **레이어**: 평평한 짙은 작업대 위에 서로 다른 역할의 종이 세 장. 실제 앞뒤 관계를 보여 주는 경우에만 겹침·회전·얕은 그림자를 쓴다.
- **프리셋**: 카탈로그 컷과 편집형 포스터의 조판을 전환한다. 사진 대신 직접 작성한 CSS 제품 도형을 사용한다.
- **생성 상태**: 그래파이트 콘솔, 단계·진행 막대·결과 요약. 상태 텍스트는 모션이 멈춰도 남는다.
- **입력**: 밝은 브리프 편집 화면, 텍스트가 중심. 오류/성공을 같은 위치에 알려 주고 현재 적용 문장을 별도로 표시한다.
- **차트**: 축·막대·수치가 함께 보인다. 클릭/터치/키보드 모두 툴팁을 사용할 수 있으며 색상만으로 수치를 전달하지 않는다.
- **작업 상세·필터**: 구분선과 행 선택으로 밀도를 만든다. 상세 정보와 집계는 같은 샘플 데이터에서 파생된다.
- **일정**: 월 제목 → 날짜 스트립 → 일정. 데이터가 없는 20일도 직접 선택해 빈 상태를 볼 수 있다.
- **작업 추가**: 입력과 현재 건수 옆에 실제 목록을 둔다. 추가한 작업이 미리보기에서도 보여야 한다.
- **선택·검토창**: 장식 대신 선택 테두리와 확인할 내용. 확인·취소와 닫힌 뒤 원래 초점으로 복귀하는 동작을 제공한다.

## 모션

실제 시간과 easing 원본은 `data.js`의 각 `item.motion`이다. 하나의 애니메이션 프리셋으로 모든 요소를 덮지 않는다. 레이어는 순차 진입, 선택은 짧은 피드백, 상세는 수평 이동, 차트는 이전 높이에서 새 높이로 전환, 폼은 결과 메시지에만 반응한다. 결과 계산은 모션 완료에 의존하지 않는다.

갤러리는 자동 시연을 하지 않는다. 카드의 컴포넌트는 viewport에서 120px 이내로 접근할 때 mount한다. 화면 밖/탭 숨김/상세창 뒤에서는 실행 중 모션을 중지한다. WAAPI 진행 중 다음 입력은 기존 전환을 취소하고 최신 상태를 사용한다. 가능한 이동은 transform·opacity로 처리하되 차트 높이 등 데이터 표현에 필요한 크기 전환은 해당 영역에 한정한다. `prefers-reduced-motion`과 상세의 모션 줄이기를 모두 지원한다. 링크 아이콘만 hover 시 150ms ease-out으로 2px 이동하며 동작 줄이기에서는 생략한다.

## 재사용과 확인

실행 HTML은 외부 라이브러리·웹폰트·사진·서버 없이 동작한다. 기존 제3자 MIT 고지는 보존하며 새 외부 코드를 가져오지 않는다. 공개 사이트의 디자인 원리 참고와 코드/자산 사용을 구분한다. 자료별 확인 수준과 라이선스는 `docs/ui-motion-resource-audit.md`에 기록한다. 1440/1180/390px의 실제 렌더링·조작 결과와 남은 한계는 `docs/ui-motion-gallery-review.md`에서 별도 보고한다.
