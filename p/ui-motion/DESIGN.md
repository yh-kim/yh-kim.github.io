# UI·모션 갤러리 디자인 기준

2026-10-19 실사용 UI 개편. `/p/ui-motion/`가 실제 컴포넌트 목록이며 `/p/ui-motion/components/`는 같은 앱을 연다. `/p/hidden-memo/ui-motion-guide/`는 같은 디자인 기준 화면이다. 기존 두 대표 화면은 별도 경로와 전용 토큰을 유지한다.

## 탐색 구조

큰 캠페인 소개 대신 제목·한 문장 설명·검색·분류·실행 목록을 먼저 보여 준다. 1440px 첫 카드 y262px, 390px y281px에서 시작한다. 좌측 208px 탐색과 두 열 목록을 사용하며 949px 이하는 상단 탐색, 699px 이하는 한 열이다. 카드 폭은 1440px에서559px, 1180px에서450.5px, 390px에서349px이다(스크롤바 포함 실제 측정).

목록의 입력·메뉴·버튼·네이티브 모달은 모두 작동한다. 카드 전체에는 링크·클릭 처리·포인터 커서를 붙이지 않는다. **자세히 보기 버튼만** 갤러리 상세를 연다. 초기화는 해당 카드 상태만 초기화한다. 검색은 현재 이름·옛 이름·용도·설명·분류와 연결하고, 빈 결과에서 조건을 초기화할 수 있다. 모든 12개 ID와 기존 해시는 남긴다.

## 모션·실행

상태 연결은 대체로150–240ms, 차트300ms다. 업로드 진행은 선형, 차트는 `cubic-bezier(.2,0,.2,1)`, 오버레이는 `cubic-bezier(.22,1,.36,1)`, 나머지 짧은 피드백은 `cubic-bezier(.2,.8,.2,1)`을 기준으로 한다. CSS의 hover/pressed는 120–180ms 내의 짧은 반응이다. 무한 반복·진입 자동 시연은 없다.

`prefers-reduced-motion`과 상세·내보내기에서의 모션 줄이기를 적용한다. 핵심 수치·선택·결과는 모션 없이도 표시한다. 관찰자 기반 지연 마운트와 화면 밖 중단을 사용한다. 메인 목록은 두 대형 대표 장면 모듈을 가져오지 않는다. 새 이미지·웹폰트·WebGL·라이브러리 의존성은 없다.

목록·상세·내보내기는 같은 마크업/CSS/상태 함수를 사용한다. 단일 HTML은 외부 파일 없이 동작한다. 모든 제출·저장·업로드·주문·예약은 로컬 샘플이며 실제 전송·결제·영구 저장은 하지 않는다. 서비스에 옮길 때는 API·권한·서버 검증을 연결한다.
