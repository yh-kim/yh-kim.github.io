# UI·모션 갤러리 디자인 기준

2026-10-19 두 번째 시각 검토. `/p/ui-motion/components/`와 개별 데모 12개에 적용한다. 기존 AI Workspace·Project Dashboard 대표 장면은 별도 토큰을 유지한다.

## 탐색과 데모의 역할

갤러리는 흰 바탕의 조용한 색인이다. 데모 안에는 실제 조작할 제품 화면이 들어간다. 목록 제목, 상세 제목, 데모의 설명 제목을 세 번 반복하지 않는다. `.study-head` 설명은 갤러리에서 숨기고 제품 안의 제목과 제어는 남긴다. 항목을 감추거나 개수를 줄이지 않는다.

| 항목 | 구현 값 | 이유 |
| --- | --- | --- |
| 탐색 바탕·표면 | `#ffffff` | 여러 데모의 색과 경쟁하지 않는다. |
| 본문·보조 | `#202632` / `#677180` | 흰 바탕 대비 각각 약 15.2:1 / 4.9:1. 보조 문장도 읽을 수 있게 한다. |
| 경계·강조·초점 | `#e3e7ed` / `#335cff` / `#265ec8` | 구획은 가볍게, 선택·키보드 위치는 분명하게 한다. |
| 제목 | 데스크톱 32px, 모바일 29px / 1.3 / 720 | 목록이 첫 화면에 보이도록 소개 높이를 제한한다. |
| 목록 제목·설명 | 18px / 1.35 / 650, 설명 12px / 1.7(모바일 13px) | 이름과 체험할 기능의 위계를 나눈다. |
| 본문·제어·보조 | 기본 14px / 1.6, 제어 12–13px, 라벨 11–12px | 한국어 문장과 숫자의 가독성을 먼저 확보한다. |
| 폭·열 | 최대 1536px, 1200px 이상 3열 / 600–1199px 2열 / 이하 1열 | 실제 데모를 조작할 너비를 확보한다. |
| 여백·간격 | 바깥 40 / 28 / 18px, 열 24px, 행 32px; 내부 기본 4·8·12·16·24·36px | 일관된 리듬과 작은 화면의 터치 여유를 만든다. |
| 반경 | 미리보기·상세 프레임 14px, 검색 9px, 필터 7px | 탐색은 일관되게 하되 내부 제품 표면까지 강제하지 않는다. |
| 그림자 | 목록 프레임 없음; 상세창 `0 24px 80px #1c25192b` | 세부 구획은 선과 공간으로, 모달의 깊이만 그림자로 표현한다. |

시스템 sans-serif만 사용하며 웹폰트 요청은 없다. 한국어는 `word-break:keep-all`과 `overflow-wrap:anywhere`를 함께 사용한다. 긴 작업명은 숨기지 않고 줄바꿈한다. 검색은 실제 이름·설명·용도·분류를 찾고 URL 쿼리를 유지한다. 분류 버튼에 수를 표시하며 빈 결과와 초기화를 제공한다. 미리보기 조작과 상세 링크는 별개다.

## 데모별 표면

원본은 `component-design.js`의 공통 읽기·초점·폼 기준과 세 모듈이다. `editor-studies.js`는 제품 편집, `data-studies.js`는 업무 데이터, `feedback-studies.js`는 처리·결과 검토를 담당한다. `engine.js`는 같은 마크업·CSS·상태 함수를 미리보기/상세/독립 실행 HTML에서 사용한다.

| 데모 | 표면·주요 색 | 구성 의도 |

| 프리셋 | `#e8eef2`, 잉크 `#132b3f`, 포스터 `#0c263c`–`#22455d` | 자체 SVG 제품의 형태·광원·색과 편집 조판을 실제로 바꾼다. 광원은 제품 표현에만 쓴다. |

| 선택 | `#f1f4f0`, 제어 레일 `#193a30`, 초점 `#2d7663` | 제품·메시지·행동의 초점이 이동한다. 효과와 바뀌는 정보가 한 화면에 대응한다. |

| 작업 상세 | `#edf1f5`, 흰 표면, 잉크 `#1e3145` | 좁은 인박스와 정보 패널. 넓은 화면은 두 열, 좁은 자체 컨테이너는 한 열이다. |
| 필터 | 흰 표면, 잉크 `#223545`, 가는 구분선 | 중첩 카드보다 도구형 목록·상태·숫자를 강조한다. |

| 작업 추가 | `#e9f4ef`, 잉크 `#193c32`, 동작 `#168363` | 한 줄 입력과 실제 새 행이 같은 영역에 보인다. 중복·길이 오류와 성공을 구분한다. |

| 작업 검토 | `#f8f5ef`, 표면 `#fffdf9`, 잉크 `#42382f`, 동작 `#73513a` | 선택한 업무의 담당자·마감을 확인하는 조용한 승인 화면이다. |

제품 표면은 기능에 따라 4–18px 반경, 1px 경계, 한정된 그림자를 사용한다. 예: 제품 레이어 `0 16px 24px #27304426`, 펼친 레이어 `0 4px 12px #2730441d`, 데이터 카드 `0 12px 28px -22px #2c4c70`. 모든 데모에 같은 그림자나 배경을 씌우지 않는다. 제품 일러스트는 직접 작성한 SVG/CSS이며 사진·외부 아이콘 패키지·폰트를 추가하지 않는다.

미리보기 430px. 전체 최대 폭 840px, 기본 최소 560px, 일정 최소 440px. 데모 여백은 목적에 따라 카드 18–24px·전체 22–36px. 주요 제품 제목 15–23px/1.3, 본문 13–14px/1.5, 보조 11–12px. 작은 영문 번호는 정보 전달이 없는 장식에 한정한다. 조작 버튼 높이는 44px 이상이며 키보드 초점은 3px+offset 3px다.

## 상태와 모션

| 동작 | 시간·곡선 | 목적 |
| --- | --- | --- |
| 레이어 펼침·복귀 | 650ms `cubic-bezier(.18,.85,.2,1)` | 포개진 위치에서 읽을 수 있는 세 층으로 이어진다. |
| 제품 컷·포스터 | 700ms `cubic-bezier(.2,.75,.2,1)` | 같은 제품이 이동·회전하며 구도가 바뀐다. 색 500ms, 광원 300ms. |
| 시선 선택 | 550ms `cubic-bezier(.2,.8,.2,1)` | 테두리가 다음 정보 영역으로 이어진다. |
| 처리 진행 | 1800ms linear, 결과 240ms | 단계와 진행률이 일치한다. 취소·중복 실행 방지를 제공한다. |
| 차트 | 450ms `cubic-bezier(.2,0,.2,1)`, 막대 간 25ms | 현재 보이는 높이에서 최신 값으로 전환한다. |
| 작업 상세·일정 | 220ms `cubic-bezier(.2,.8,.2,1)` | 8px 이동·페이드로 정보 변경만 알린다. |
| 필터·새 행 | 260ms, 필터 `cubic-bezier(.2,0,.2,1)` | 기존 행 위치를 읽어 FLIP 전환하고 새 행만 10px 이동·페이드한다. |
| 입력 피드백 | 성공 200ms, 오류 180ms | 제출 결과를 알리며 오류 입력은 X ±4px 범위로 반응한다. |
| 검토 모달 | 열기 180ms / 닫기 140ms `cubic-bezier(.2,.8,.2,1)` | 8px·.985배 범위로 깊이를 표현한다. 포커스 이동/순환/복귀와 Escape를 제공한다. |

CSS 상태 전환은 현재 계산 위치에서 역전한다. WAAPI는 목표별 기존 전환을 취소하고 최신 상태로 전환한다. 단계 진행은 화면 밖·문서 숨김·상세 뒤에서 중지한다. 사용자가 시작한 유한 CSS 전환에는 자동 반복이 없다. `prefers-reduced-motion`과 상세 체크박스 모두 중간 이동을 생략하며 데이터와 완료 정보는 그대로 남는다. 속도 0.25×는 WAAPI와 CSS의 `--study-speed`에 함께 적용한다. CSS 전환에 작동하지 않는 일시정지 버튼은 노출하지 않는다.

## 재사용과 검증

복사 HTML은 같은 마크업·스타일·wire와 해당 enhancer 함수, 한국어 샘플 데이터가 포함된다. 외부 의존성·이미지·폰트·서버 요청이 없다. 대표 장면에서 사용한 기존 Lucian #280 MIT 노이즈 고지는 보존한다. 이번 추가 작업은 참고 패턴을 독립 구현했다. 확인 수준·라이선스는 `docs/ui-motion-resource-audit.md`, 참고 400개 관찰은 `docs/ui-motion-reference-audit-summary.md`, 이번 실제 검증과 한계는 `docs/ui-motion-gallery-revision-review.md`에 구분해 기록한다.
