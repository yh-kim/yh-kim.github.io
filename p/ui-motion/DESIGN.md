# UI·모션 디자인 기준

2026-10-19. 갤러리는 컨셉 컬렉션 `/p/ui-motion/`, 컨셉별 컴포넌트와 기준 `/paper/`, `/object/`, `/frame/`, 전체 12개 목록 `/components/`로 나눈다. 각 컨셉의 `#design`이 이 기준의 실제 시각 예시다. 기존 ID·별칭·딥링크·두 대표 화면 URL은 보존한다.

## 탐색과 내용

상세 제목 아래에 소개·홍보·반복 설명을 붙이지 않는다. 제목, 분류, 실제 데모, 명시적 자세히 보기만으로 읽히게 한다. 설명이 필요한 경우 상세의 사용 명세에서 항목과 값으로 제공한다. 라벨·오류·결과·위험한 작업의 확인 문구는 기능의 일부이므로 유지한다.

홈은 최대 960px의 세로 리스트다. 카드 높이 84px, 간격 10px, 패딩 14×16px, 모서리 11px, 실제 화면 썸네일 54px이다. 390px에서는 패딩 13×12px, 썸네일 50px, 제목 16px, 설명 12px 한 줄 말줄임을 쓴다. 전체 카드는 하나의 링크이며 내부 버튼이 없다. 홈은 데모 런타임을 불러오지 않는다. 짧은 컨셉 설명은 이번 선택 리스트의 명시적 요구다.

상세의 공통 헤더는 64px, 탐색 폭은 184px(1180px에서는 172px), 페이지 제목은 28px/1.3/730이다. 콘텐츠는 넓은 편집 지면과 두 열을 섞고, 스토어는 상품·주문 전체 폭과 보관함/예약 5:7, 업무 도구는 차트/설정 8:4(1180px에서는 7:5)다. 699px 이하는 읽기 순서 한 열이다. 탐색은 같은 위치·동작을 유지한다.

목록 전체나 빈 영역을 클릭해 상세로 이동하지 않는다. 미리보기는 목록·상세·독립 HTML에서 같은 구현이다. 자세히 보기 버튼만 갤러리 상세를 연다. 검색은 이름·이전 이름·용도·분류와 연결하며 빈 결과에서 초기화한다.

## 활자·간격·표면

외부 글꼴 없이 시스템 sans-serif를 사용한다. 숫자는 tabular-nums로 정렬한다. 한글은 `keep-all`과 긴 문자열의 `anywhere` 줄바꿈을 사용한다.

아이콘은 24 좌표계, 17–18px, 1.7px 선과 둥근 끝을 공유한다. 주요 행동·탭·필터는 최소 44px 높이, 키보드 초점은 3px 외곽선이다. 날짜와 주문 선택은 넓은 label로 터치 영역을 확보한다. 넓은 표는 좁은 화면에서 두 줄 행으로 바뀌어 금액·상태까지 표시한다.

## 모션과 상태

선택·저장은 150–180ms, 메뉴는 160–170ms, FAQ 답변은 220ms, 차트는 300ms, 드로어는 열기 240ms/닫기 140ms를 기준으로 한다. 처리 진행은 선형, 차트는 `cubic-bezier(.2,0,.2,1)`, 오버레이는 `cubic-bezier(.22,1,.36,1)`, 짧은 피드백은 `cubic-bezier(.2,.8,.2,1)`을 사용한다. 모든 컴포넌트에 공통 등장 애니메이션을 붙이지 않는다.

전환 중 다시 조작하면 같은 노드의 이전 실행을 취소하고 현재 계산된 transform·opacity·height에서 이어 간다. Escape·취소·재열기를 지원하며 네이티브 모달은 포커스를 옮기고 닫힌 뒤 복귀한다. 업로드에는 파일 선택 버튼 대안을 둔다. `prefers-reduced-motion`과 화면의 모션 줄이기를 적용한다. 정보·선택·결과는 모션 없이도 읽힌다.

## 구현과 확장

- `site-concepts.js`: 컨셉 이름·소속 ID·색·활자·간격·모션의 단일 레지스트리.
- `gallery.js`, `collection-home.js`, `gallery.css`: 탐색·지연 마운트·작은 컨셉 리스트와 실제 화면 크롭.
- `site-runtime.js`: --space-1:4px, --space-2:8px, --space-3:12px, --space-4:16px, --space-6:24px, --space-8:32px. 제어 모서리는 paper 2px, object 8px, frame 6px. 데모 CSS에서 실제 사용한다.
- `gallery-design.js`: 컨셉별 토큰·활자·간격·직접 조작하는 모션 표본.
- `site-inputs.js`, `site-content.js`, `site-runtime.js`: 같은 코드로 목록·상세·독립 HTML 실행.

새 컨셉은 레지스트리와 숨김 HTML 진입점을 추가한다. 기존 ID를 재사용하거나 삭제하지 않는다. 실제 대표 화면을 크롭한 썸네일을 함께 등록한다. 추가 후 소속 중복·누락·경로·모든 폭의 렌더링을 확인한다.

화면 밖 데모는 중단하고 필요한 항목만 마운트한다. 메인은 기존 대형 AI/프로젝트 장면 모듈을 불러오지 않는다. 새 웹폰트·WebGL·런타임 라이브러리·API 의존성은 없다. 상품 사진은 브랜드 없는 자체 생성 WebP 두 장(각 640×640, 합계 약 33KB)이며 같은 조명과 중성 배경을 쓴다. 원본과 동일한 data URI를 복사 HTML에 포함한다. 생성 프롬프트는 docs/ui-motion-gallery-product-assets-v2.md에 기록했다. 제출·업로드·예약·주문은 로컬 시뮬레이션이며 서비스 연결은 실제 API·권한·서버 검증을 붙이는 별도 작업이다.

| 동작 | 시작 → 종료 | 시간 / easing |
| --- | --- | --- |

| 버튼 | 기본 → 눌림 y 1px·색 변화 | 140–160ms / ease-out |

| 메뉴 | opacity 0 → 1, y -7 → 0 | 170ms / cubic-bezier(.16,1,.3,1) |
| FAQ | opacity 0 → 1, y -7 → 0px | 220ms / cubic-bezier(.22,1,.36,1) |
| 차트 | 현재 값 높이 → 새 데이터 높이 | 300ms / cubic-bezier(.2,0,.2,1) |
| 장바구니 | opacity 0 → 1, x 24 → 0px / 역방향 | 240ms / 140ms / cubic-bezier(.22,1,.36,1) |
| 업로드 | 처리량 0 → 100%·상태 교체 | 데모 진행 시간 / linear |
| 저장·예약 | 진행 중 → 성공/오류, opacity .5 → 1 | 180–220ms / cubic-bezier(.2,.8,.2,1) |
