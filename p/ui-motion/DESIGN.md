# UI·모션 디자인 기준

2026-10-19. 갤러리는 컨셉 컬렉션 `/p/ui-motion/`, 컨셉별 컴포넌트와 기준 `/paper/`, `/object/`, `/frame/`, 전체 12개 목록 `/components/`로 나눈다. 각 컨셉의 `#design`이 이 기준의 실제 시각 예시다. 기존 ID·별칭·딥링크·두 대표 화면 URL은 보존한다.

## 탐색과 내용

제목 아래에 소개·홍보·반복 설명을 붙이지 않는다. 제목, 분류, 실제 데모, 명시적 자세히 보기만으로 읽히게 한다. 설명이 필요한 경우 상세의 사용 명세에서 항목과 값으로 제공한다. 라벨·오류·결과·위험한 작업의 확인 문구는 기능의 일부이므로 유지한다.

홈은 12열 배치에서 콘텐츠 7열, 스토어 5열, 업무 도구는 가로형으로 구성한다. 세 컨셉을 같은 카드 세 장으로 만들지 않는다. 콘텐츠 목록은 넓은 편집 지면과 두 열을 섞고, 스토어는 열린 상품 그리드, 업무 도구는 좁은 간격의 도구 패널을 사용한다. 680px 이하는 모두 읽기 순서대로 한 열이다. 탐색은 동일한 위치·동작으로 유지한다.

목록 전체나 빈 영역을 클릭해 상세로 이동하지 않는다. 미리보기는 목록·상세·독립 HTML에서 같은 구현이다. 자세히 보기 버튼만 갤러리 상세를 연다. 검색은 이름·이전 이름·용도·분류와 연결하며 빈 결과에서 초기화한다.

## 실제 색상

| 토큰 | 콘텐츠 사이트 | 온라인 스토어 | 업무 도구 |
| --- | --- | --- | --- |
| 바탕 | `#f7f7f5` | `#f5f3ef` | `#f3f5f9` |
| 표면 | `#ffffff` | `#ffffff` | `#ffffff` |
| 본문 | `#171717` | `#26231f` | `#17243a` |
| 보조 | `#66645f` | `#716a61` | `#5f7286` |
| 행동·선택 | `#be3c2d` | `#40382f` | `#2558d9` |
| 경계 | `#deded8` | `#ded9d0` | `#dce2eb` |

탐색은 중립적인 흰 바탕이다. 콘텐츠는 강한 잉크 대비와 작은 붉은 행동, 스토어는 상품을 받치는 따뜻한 중성색과 차콜, 도구는 청회색 작업 면과 파란 선택을 사용한다. 전체 배경을 강조색으로 덮지 않는다. 대표 보조 글자/바탕 대비는 각각 5.51:1, 4.81:1, 4.54:1이다. 흰 글자/행동색은 각각 5.42:1, 11.51:1, 6.04:1이다. 비활성 상태는 별도로 표시한다.

## 활자·간격·표면

외부 글꼴 없이 시스템 sans-serif를 사용한다. 스토어의 숫자·일부 영문 구획만 시스템 serif를 허용한다. 한글은 `keep-all`과 긴 문자열의 `anywhere` 줄바꿈을 사용한다.

| 항목 | 콘텐츠 | 스토어 | 도구 |
| --- | --- | --- | --- |
| 페이지 제목 | 34–43px / 1.08 / 790 | 32–41px / 1.2 / 400 | 28–34px / 1.2 / 740 |
| 내부 제목 | 24–28px / 1.25 / 740 | 24–28px / 1.25 / 650 | 20–26px / 1.25 / 700 |
| 본문·제어 | 14px / 1.65 | 14px / 1.55 | 13–14px / 1.5 |
| 보조 정보 | 11–12px / 1.6 | 11–12px / 1.6 | 11–12px / 1.5 |
| 간격 | 8·12·18·24·32px | 8·12·16·24·32px | 6·10·16·20·28px |
| 버튼 | 각진 면·밑줄 링크 | 구매·선택에 둥근 pill | 4–6px 모서리의 작은 제어 |
| 깊이 | 구분선 중심, 메뉴만 얕은 그림자 | 상품 면과 드로어 | 표·툴바는 선, 확인창만 그림자 |

아이콘은 24 좌표계, 17–18px, 1.7px 선과 둥근 끝을 공유한다. 주요 행동·탭·필터는 최소 44px 높이, 키보드 초점은 3px 외곽선이다. 모바일 날짜 버튼은 44.4×48px, 주문 선택 label은 44×44px로 실측했다. 넓은 표는 좁은 화면에서 두 줄 행으로 바뀌어 금액·상태까지 표시한다.

## 모션과 상태

선택·저장은 150–180ms, 메뉴는 160–170ms, FAQ 높이는 220ms, 차트는 300ms, 드로어는 열기 240ms/닫기 140ms를 기준으로 한다. 처리 진행은 선형, 차트는 `cubic-bezier(.2,0,.2,1)`, 오버레이는 `cubic-bezier(.22,1,.36,1)`, 짧은 피드백은 `cubic-bezier(.2,.8,.2,1)`을 사용한다. 모든 컴포넌트에 공통 등장 애니메이션을 붙이지 않는다.

전환 중 다시 조작하면 현재 위치에서 이어 간다. Escape·취소·재열기를 지원하며 네이티브 모달은 포커스를 옮기고 닫힌 뒤 복귀한다. 업로드에는 파일 선택 버튼 대안을 둔다. `prefers-reduced-motion`과 화면의 모션 줄이기를 적용한다. 정보·선택·결과는 모션 없이도 읽힌다.

## 구현과 확장

- `site-concepts.js`: 컨셉 이름·소속 ID·색·활자·간격·모션의 단일 레지스트리.
- `gallery.js`, `collection-home.js`, `gallery.css`: 탐색·지연 마운트·홈의 실제 미리보기.
- `gallery-design.js`: 컨셉별 토큰·활자·간격·직접 조작하는 모션 표본.
- `site-inputs.js`, `site-content.js`, `site-runtime.js`: 같은 코드로 목록·상세·독립 HTML 실행.

새 컨셉은 레지스트리와 숨김 HTML 진입점을 추가한다. 기존 ID를 재사용하거나 삭제하지 않는다. 별도 카드 커버가 없어도 첫 컴포넌트를 실제 미리보기로 표시한다. 추가 후 소속 중복·누락·경로·모든 폭의 렌더링을 확인한다.

화면 밖 데모는 중단하고 필요한 항목만 마운트한다. 메인은 기존 대형 AI/프로젝트 장면 모듈을 불러오지 않는다. 새 웹폰트·사진·WebGL·라이브러리·API 의존성은 없다. 상품 실루엣은 자체 CSS다. 제출·업로드·예약·주문은 로컬 시뮬레이션이며 서비스 연결은 실제 API·권한·서버 검증을 붙이는 별도 작업이다.
