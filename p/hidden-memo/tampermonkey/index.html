방탈출 예약 자동 입력

코드를 설치한 뒤 예약 페이지의 왼쪽 아래 버튼을 길게 눌러 이름과 전화번호를 저장하세요. 이후 버전은 Tampermonkey에서 자동 업데이트됩니다.

사용 방법

코드를 복사해 Tampermonkey에 설치하세요. 예약자 정보가 없으면 왼쪽 아래 버튼에 ‘예약자 정보 없음’이 표시되고 자동 입력은 시작되지 않습니다. 버튼을 길게 눌러 이름과 전화번호를 입력하세요. 정보가 저장된 뒤에는 같은 버튼을 길게 눌러 자동 제출을 켜거나 끌 수 있습니다. 자동 제출은 기본으로 꺼져 있습니다.

이름과 전화번호는 예약 페이지에서 입력받아 Tampermonkey의 유저스크립트 저장소에 보관하며, 스크립트가 업데이트돼도 유지됩니다. 자동 제출 설정은 각 예약 사이트의 로컬 저장소에 보관됩니다.
