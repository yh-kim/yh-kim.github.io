방탈출 예약 자동 입력

예약자 정보를 한 번 입력하면 일곱 사이트에서 동작하는 통합 UserScript 코드가 완성됩니다.

코드 설정

이름과 전화번호만 입력하세요. 예약 인원은 각 사이트의 최소 인원으로 선택됩니다. 자동 제출 초기값은 저장된 설정이 없을 때만 사용되며, 이후에는 예약 사이트의 왼쪽 아래 상태 버튼을 길게 눌러 변경합니다.

입력한 이름과 전화번호는 저장하거나 전송하지 않고, 현재 화면의 코드에만 반영됩니다. 자동 제출 설정만 각 예약 사이트의 로컬 저장소에 보관됩니다.
